# Code of Conduct

We want a calm, useful, and respectful project for contributors and users.

## Expected behavior

- Use clear and respectful language.
- Discuss code, documentation, and evidence rather than people.
- Accept correction and keep technical disagreements focused.
- Protect private data, credentials, and security reports.

## Unacceptable behavior

- Harassment, threats, discrimination, or personal attacks.
- Publishing another person's private information.
- Deliberate disruption, spam, or malicious code.
- Public disclosure of an unpatched security issue.

## Enforcement

Maintainers may edit, close, or remove content and may restrict participation when needed to keep the project safe. Report a private conduct concern through the [private report route in SECURITY.md](SECURITY.md). If that route is not available, use the [maintainer profile](https://github.com/ttaatoo) to request a private channel. The project publishes no security email. Use a public issue or pull request only for a concern that contains no private information.
